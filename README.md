# DSP

This repository contains the code of analysis and visiualization associated with
**"Spatial transcriptomic atlas of human pancreatic islet endocrine cells and macrophages across adiposity and type 2 diabetes"**.

Pre-processed data, including normalized gene expression matrix and metadata for downstream analysis, have been deposited in Zenodo (https://doi.org/10.5281/zenodo.21976912).
